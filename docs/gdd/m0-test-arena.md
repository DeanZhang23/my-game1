## 1. 一句话与目标

玩家在进入战斗前掷 3 枚命运骰、锁骰与重掷，再把最多 5 名单位摆进 3×3 格；战斗自动结算，同调可打开一次战术窗口。

**M0 验收：**

- 六种骰面、锁骰、免费 1 次重掷、裂纹与腐蚀，在 TestArena 里可玩。
- 3×3 我方 / 3×3 敌方可布阵；战斗中默认不可移动。
- 用 1–2 个占位单位跑通一场战斗（不必做 8 人正式名册）。
- 战斗公式有自动化测试；同一 Golden Seed 可完整复盘（骰点、伤害、胜负一致）。

## 4. 命运骰

### 4.1 流程

1. 进入 Setup 后掷出 **3 枚** 骰子（六面均匀，见 §4.3）。
2. 玩家可 **锁骰**（锁定的骰本轮不重掷）。
3. 每场 **免费重掷 1 次**（只重掷未锁定的骰）。
4. 之后每次重掷：获得 **1 层裂纹**（`status_crack`）。裂纹上限 3 层。达 3 层后本场施加腐蚀（§4.2）；仍允许继续重掷，但不再加层。
5. 玩家确认出征（或跳过全部重掷）后，按最终 3 面结算组合与效果，进入 Countdown。

未锁定也可直接重掷（三枚全重掷）。三枚全锁则重掷无效果，不消耗免费次数、不加裂纹。

### 4.2 裂纹与腐蚀（M0 提案，见 §12）

- 0–2 层：无额外伤害修正。
- 3 层：本场所有最终伤害（双方）再乘 `1.15`，写入公式中的「伤害修正」，称为腐蚀（`mod_corrosion`）。
- 腐蚀在确认出征时若已满 3 层即生效，持续整场，不衰减。

### 4.3 骰面

每枚骰子六面等权。效果在 **确认出征时** 结算到本场战斗，除非另有说明。

| ID | 显示名 | 效果 | 本地化 key 前缀 |
|---|---|---|---|
| `face_sword` | 剑 / 锋刃 | 全队攻击 +12%；前排每个单位获得 1 层锐意（`status_keen`） | `face.sword` |
| `face_shield` | 盾 / 壁垒 | 全队护甲 +8；前排获得 15% 最大生命的护盾 | `face.shield` |
| `face_star` | 星 / 秘仪 | 后排初始能量 +20；技能伤害 +10% | `face.star` |
| `face_feather` | 羽 / 疾行 | 全队攻速 +15%；每个单位的首个技能冷却 −1 秒 | `face.feather` |
| `face_coin` | 币 / 贪欲 | 本场胜利后金币 +6（M0 无商店，仍计入结算并写日志） | `face.coin` |
| `face_skull` | 颅 / 献祭 | 全队立即损失 5% **当前**生命（至少留 1 点，已阵亡不再扣）；获得 1 枚本场临时万能符印（`token_wild`） | `face.skull` |

**锐意（`status_keen`，M0 提案，见 §12）：** 1 层使该单位下一次造成的普攻或技能伤害 +20%，命中后消耗。多枚剑可叠层，逐次消耗。不受双生/同调的百分比放大（层数仍按骰面次数发放）。

**万能符印（`token_wild`，M0 提案，见 §12）：** 本场临时，不占骰槽、不可重掷。结算组合时，可指定为任意一种骰面，用于凑双生或同调。一场最多按实际获得枚数使用（三枚颅可获 3 枚）。若无助于组合，可闲置。

**护盾：** 见 §8.4。盾面提供的前排护盾在进入 AutoCombat 时挂上，持续 8 秒。

**能量：** M0 占位单位技能能量上限 100。初始能量默认 0，再加星面的后排 +20。能量增长速度写在单位定义上（见 §7.2）。

### 4.4 组合

先看 3 枚骰的最终面，再把万能符印指定进去（自动策略：选能使组合档位最高的面；同档时按 §4.3 表从上到下的 ID 顺序）。

| 组合 | 条件 | 效果 |
|---|---|---|
| 同调 `combo_attunement` | 3 张同面（含符印凑齐） | 该面**可叠加的数值效果** ×1.80；解锁 **1 次** 专属战术窗口 |
| 双生 `combo_twin` | 恰好 2 张同面，且未构成同调 | 该面可叠加的数值效果 ×1.35 |

- 数值效果指：攻击 / 护甲 / 护盾生命比例 / 能量 / 技能伤害 / 攻速 / 冷却减免 / 金币 / 献祭生命损失。离散层数（锐意、符印枚数）不乘系数。
- 同时只生效档位最高的一套组合（3 同面 = 只算同调，不再另算双生）。
- 系数向下取整发生在代入公式之后：先用放大后的浮点修正参与计算，再按 §8 取整。金币结果向下取整为整数。
- 例：三枚剑 → 全队攻击 +12% × 1.80 = +21.6%；前排仍各 1 层锐意（来自三枚剑应是 3 层还是 1 层：按「每个造成剑面的骰发 1 层」，同调 3 剑 = 前排各 3 层，但层数本身不乘 1.80）。
- 双生剑（2 剑 1 其他）：攻击 +12% × 1.35 = +16.2%；前排各 2 层锐意。

命途、逆命见 §10，M0 不实现。

## 5. 战斗状态机

允许状态：`Setup` → `Countdown` → `AutoCombat` → `TacticalWindow` → `Resolve`。

### 5.1 转移

| 从 | 到 | 条件 |
|---|---|---|
| Setup | Countdown | 阵型合法（至少 1 名我方单位）且玩家确认出征 |
| Countdown | AutoCombat | 倒计时结束（M0 建议 3 秒，Inspector 可调） |
| AutoCombat | TacticalWindow | 本场有同调，且本场尚未打开过窗口，且达到窗口触发点（§5.4） |
| TacticalWindow | AutoCombat | 玩家确认、跳过，或窗口超时 |
| AutoCombat | Resolve | 一方全灭，或战斗时长达到 **150 秒**（超时 = 失败） |

无同调时，AutoCombat 不进入 TacticalWindow，直接等到胜负或超时。

### 5.2 Setup

- 摆放我方占位单位到 3×3 我方格（§6）。敌方用预设摆法（数据驱动，可写在测试关卡 SO 里）。
- 掷骰、锁骰、重掷、确认（§4）。
- 开战种子在进入 Setup、第一次掷骰前生成（或由 Golden Seed 测试注入）。之后所有随机只走该种子。

### 5.3 Countdown

冻结操作（不可再改阵、改骰）。Presentation 可播 3 秒倒计时；Simulation 推进相同的逻辑时间。

### 5.4 AutoCombat 与战术窗口

自动攻击与技能按公式与冷却推进。单位战斗中不可移动，除非某技能定义了位移（M0 占位技能不要带位移）。

**同调战术窗口（M0 灰盒）：**

- 触发点：进入 AutoCombat 后 **8 秒**（Inspector 可调）。若 8 秒前战斗已结束，则不再打开窗口。
- 暂停 Simulation 的战斗时钟；玩家有 **8 秒** 点确认或跳过。超时视为跳过。
- M0 **不实现** 六种面的正式专属战术（不改伤害、不召唤、不位移）。只要求：状态切得到、日志记一笔 `tactical_window_opened` / `confirmed` / `skipped`、然后回到 AutoCombat。
- 正式战术内容放到后续切片，按同调面绑定。

### 5.5 Resolve

- 胜利：全部敌方单位阵亡，且至少 1 名我方存活。
- 失败：我方全灭，或 150 秒超时。
- 结算金币（含币面；失败默认不发币面金币，避免用失败刷金。若需改规则见 §12）。
- 写最终事件，停 Simulation。

## 6. 阵型

- 队伍上限 **5**。我方 3×3、敌方 3×3，两阵相对。
- 槽位 ID（我方，面向敌方）：

```
后排  ally_a1  ally_a2  ally_a3
中排  ally_b1  ally_b2  ally_b3
前排  ally_c1  ally_c2  ally_c3
        —— 战场中线 ——
前排  enemy_c1 enemy_c2 enemy_c3
中排  enemy_b1 enemy_b2 enemy_b3
后排  enemy_a1 enemy_a2 enemy_a3
```

- **前排** = `*_c*` 一行；**后排** = `*_a*` 一行；中排 `*_b*` 不吃前排/后排专属效果（仍吃全队效果）。
- 同一格最多 1 个单位。Setup 阶段可改站位；Countdown 起不可改。
- 战斗中不可移动（除非技能明确位移）。M0 不做位移技能。
- M0 用 **1–2 个占位单位** 验证布阵即可，不要做 8 名正式单位。

## 8. 核心公式

全部对最终结果 **向下取整** 为整数。护甲 / 魔抗参与计算时，先 `max(0, 护甲或魔抗)`。暴击在得到「最终伤害」（护甲/魔抗与伤害修正之后）再乘暴击。

### 8.1 普攻（物理）

```
preCrit = floor( max(1, 攻击 × 技能倍率 × (100 / (100 + max(0, 护甲))) × 伤害修正) )
damage  = 若暴击: floor( preCrit × (1 + 暴击伤害) ); 否则 preCrit
```

默认暴击伤害 = 0.50。

### 8.2 法术

```
preCrit = floor( max(1, 法强 × 技能倍率 × (100 / (100 + max(0, 魔抗))) × 伤害修正) )
damage  = 若暴击: floor( preCrit × (1 + 暴击伤害) ); 否则 preCrit
```

### 8.3 攻速

```
间隔 = max(0.35, 基础攻击间隔 / (1 + 攻速加成))
```

攻速加成如羽面 +0.15（再乘双生/同调系数）。间隔下限 **0.35 秒**。

### 8.4 护盾

- 先扣护盾，再扣生命。护盾不能变成负值；溢出伤害打到生命。
- 默认 8 秒后消失（剩余护盾清零）。同一单位多段护盾：M0 合并为一个池，**以最早到期的一段刷新 8 秒总窗**（简单、可测）。若后续要分段过期，另开切片。
- 生命扣到 0 即阵亡；献祭扣血不得把存活单位扣到 0 以下（至少留 1）。

### 8.5 伤害修正（乘区，默认 1.0，相乘）

至少包括：

| 修正 | 来源 |
|---|---|
| 剑面全队攻击已体现在「攻击」数值，不在此重复乘 | — |
| 星面技能伤害 +10%（及组合放大） | 仅技能，不含普攻 |
| 锐意 +20% / 层（即将命中的那一次） | 普攻或技能 |
| 腐蚀 1.15 | 3 层裂纹后，所有最终伤害（暴击前的「伤害修正」） |

实施时：先把攻击力、护甲等面板算完，再把本表乘区代入「伤害修正」。不要把攻击 +12% 既加在面板又乘进修正。

### 8.6 工作示例（供单测对照）

无修正、无暴击：攻击 18，倍率 1.0，目标护甲 8。

```
18 × 1.0 × (100 / 108) × 1.0 = 16.666… → floor = 16
```

同上并暴击（暴伤 0.50）：`floor(16 × 1.50) = 24`。

剑双生后攻击为 `18 × (1 + 0.12 × 1.35) = 18 × 1.162 = 20.916`，先向下取整到面板还是保持浮点？**M0 规定：面板加成保留到计算过程，只在公式最终 `preCrit` 与暴击后再 `floor`。** 若 20.916 × (100/108) = 19.366 → `floor` = 19（无暴击）。

## 9. 事件日志与 Golden Seed

每场产生有序事件日志（至少）：`battle_start`（含种子）、`dice_roll`、`dice_lock`、`dice_reroll`、`crack_gained`、`dice_commit`、`combo_resolved`、`unit_spawned`、`damage`、`shield_applied`、`shield_expired`、`heal_or_hp_loss`、`skill_cast`、`tactical_window_*`、`unit_death`、`battle_end`（胜负、时长、金币）。

**Golden Seed：**

- 一组固定种子 + 固定操作脚本（例如：第一次结果后锁第 1 枚、重掷、不再重掷、站位 C2 + A2）。
- 纯 Simulation 跑完，断言：最终骰面、裂纹层数、组合、每次 `damage` 数值与目标、胜负、金币，与黄金文件一致。
- 改公式必须更新黄金文件，并在 PR 说明原因。

## 10. 命途 / 逆命（只写规则，M0 不实现、不做 UI）

留作后续切片，防止 M0 偷做。

- **命途（`system_fate`）：** 跨场累计同调面。同一面同调达到规定次数后，解锁该面的命途修正（长期、偏稳定加成）。依赖路线与元进度，M0 不做存储与入口。
- **逆命（`system_defy`）：** 本场限一次，在确认出征前可将一枚未锁定骰强制改成指定面，并立即获得 1 层裂纹（已满 3 层则只改面、再触发已生效的腐蚀）。与免费重掷相互独立。M0 不做按钮与逻辑。

## 11. Engineer 票

### E1 — TestArena + 骰子 FSM + 公式测试

**目标：** 可进入 TestArena；完成掷骰 / 锁骰 / 重掷 / 裂纹 / 确认；六面与双生、同调数值按本表生效；伤害与攻速公式有单测；至少 1 组 Golden Seed 断言骰面与一场伤害复盘。

**范围：** 可以先用 2 个单位写死在测试关卡里，不必先做完整拖拽布阵 UI（布阵见 E1.1）。Simulation 与日志必须有；Presentation 用最简灰盒（按钮、骰面文字、血条、日志滚动）。

**完成标准：**

- Play Mode：打完一场，能看到骰面、组合、胜负。
- 免费重掷 1 次不加裂纹；第 2、3、4 次重掷分别到裂纹 1、2、3；第 5 次仍为 3 层且腐蚀已生效。
- 编辑器或 CI 可跑公式单测（至少包含 §8.6 两例）与 1 个 Golden Seed。
- 无 3D 模型与 3D 场景流程。

**测试：** 单测 + 手动 Play Mode 清单（掷骰、锁 1 枚再重掷、三连同面出现同调日志、超时或击杀进入 Resolve）。
