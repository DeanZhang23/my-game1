## 1. 新的核心循环

1. **Setup（战前）：** 把最多 5 个单位放到 3×3 我方格。出征时记录前 / 中 / 后排快照。 **战前不掷骰、不加骰子加成、不能锁骰、不能重掷。**
2. 点 **出征** → `Countdown`（仍约 3 秒）。
3. **AutoCombat：** 双方自动寻敌、移动、进入射程后自动攻击。战斗中 **不因战术窗口停手**，也不再出现 `TacticalWindow`。掷骰期间战斗同样继续。
4. 战斗过程中积攒 **骰子能量**。能量 ≥ 50 时玩家可掷一次 3 枚骰，然后确认（或 6 秒 / 战斗结束自动确认）；效果在确认时一次性生效（见 §4、§5）。
5. **Resolve：** 一方全灭，或 150 秒超时（失败）。币面金币仍仅胜利发放。

## 2. 寻敌、移动、攻击

**双方都会动。** 寻敌已锁定，不再修改。

### 2.1 选目标（已锁定）

每个单位始终最多锁定 1 个敌方存活目标。排序：

1. 距离自己更近（仿真平面直线距离）的优先；
2. 距离相同，则当前生命更低的优先；
3. 仍相同，则稳定 ID（槽位 ID）字典序更小的优先。

每 **0.25 秒** 用同一规则重选一次（目标死亡时立即重选）。全程确定性，不另引随机。

### 2.2 移动

- 3×3 格子只决定 **出生点**（见 §3）。进入 AutoCombat 后，单位在 TestArena 的 2D 平面上连续移动，不再吸附格子。仍是纯 2D 等距，禁止 3D 寻路或 3D 碰撞管线。
- 未进入攻击射程时：每帧直线走向 **当前目标此刻的位置**，速度为该单位的 `moveSpeed`。
- 不得走出场地边界（夹紧在 TestArena 矩形内）。
- M0 **不做** 障碍寻路、阻挡、分离力。允许单位重叠，以保证黄金种子确定性。

### 2.3 接触与攻击

- 与当前目标距离 `<= attackRange` 即进入射程：停止移动，按原攻速公式出普攻；能量满且在射程内则放技能。伤害公式仍用主文档 §8，一律不变。
- 目标走出射程、死亡或被换目标后：若新目标不在射程内，恢复移动。

### 2.4 占位单位新增字段（仅补移动与射程）

原生命 / 攻击 / 法强 / 护甲 / 魔抗 / 暴击 / 攻击间隔 / 单位技能能量 **全部不动**。只加：

| ID | moveSpeed | attackRange |
|---|---|---|
| `unit_placeholder_melee` | 3.0 单位/秒 | 0.9 |
| `unit_placeholder_caster` | 2.5 单位/秒 | 3.5 |
| `unit_placeholder_enemy`（近战） | 3.0 单位/秒 | 0.9 |

**场地尺度（M0 默认）：** 相邻格子中心距 1.5；我方前排中心到敌方前排中心 4.0。近战开局不在射程内，需走上约 1 秒。

## 3. 3×3 格子与前 / 中 / 后排

**格子只作战前放置；前中后排在出征时快照，之后整场保留。**

- Setup 规则与主文档 §6 相同（上限 5、一格一人、空阵不能出征、Countdown 后不可再改阵）。
- 出征瞬间：按当时所在格子记录前排 `*_c*`、中排 `*_b*`、后排 `*_a*`。中排只吃全队效果。
- 开战后离开格子 **不重新判定** 前中后排。骰子若在战斗中提供位置效果（锐意 / 前排护盾 / 后排能量），一律按这份出征快照发放，不用当前位置。
- 开战后 3×3 不再约束站位。

## 4. 骰子能量（最小可测方案）

新增本场资源 `fateEnergy`（骰子能量）。与单位技能能量分离：技能能量仍按单位各自的「能量 / 秒」和技能消耗 100 运转；骰子能量是 **我方队伍共享的一条池**。

### 4.1 怎么攒

开战时为 0，上限 **100**，溢出丢弃。只在 AutoCombat 期间增长。只统计 **我方** 造成的事件（敌方不积攒、M0 敌方不掷骰）。

| 来源 | 规则 | ID |
|---|---|---|
| 造成伤害（扣血） | 我方把伤害打到敌方护盾或生命时，按实际扣减量累计；每满 10 点得 1 点骰子能量，余数保留到下次 | `fate_from_damage` |
| 击杀 | 我方击杀 1 名敌人：+15 | `fate_from_kill` |
| 现有技能能量体系 | 我方单位获得技能能量时，每获得 5 点技能能量，队伍 +1 点骰子能量（余数按单位分别保留） | `fate_from_skill_energy` |
| 释放技能 | 我方单位成功释放 1 次技能：+8 | `fate_from_skill_cast` |

例子（供单测）：造成 16 点伤害 → 池 +1，余 6；再造成 16 → 池 +2，余 2。近战「能量 / 秒 = 8」则每秒 +1 骰子能量并余 3。击杀 +15 与伤害分开加，不互相折算。

### 4.2 阈值与操作花费

M0 **每场只有 1 轮** 骰子周期：能量够了掷 **一次** 3 枚，然后确认。没有重掷。

| 操作 | 花费 | 条件 |
|---|---|---|
| 掷骰 `dice_roll` | **50** | AutoCombat 中、本场尚未掷过、当前能量 ≥ 50 |
| 确认 `dice_commit` | 0 | 已掷未确认 |

**没有重掷操作，也不花费能量重掷。** 能量不足时掷骰按钮不可用，战斗继续。点掷骰时立刻扣 50，不能透支。

### 4.3 谁来操作

只有 **玩家**。M0 敌人不掷骰、不抢能量。灰盒用按钮：掷骰 / 确认。黄金种子测试用脚本在指定逻辑时刻调用同一 API（见 §6）。

### 4.4 会不会暂停自动战斗（已确认：不暂停）

掷骰、等待确认期间，双方单位继续寻敌、移动、攻击，骰子能量继续积攒（但本场已掷过就不能再掷第二次）。

- 掷出后玩家有 **6 秒** 可提前确认。
- 超时未确认：自动确认（`dice_commit`，原因 `timeout`）。
- 若战斗在确认前结束：进入 Resolve 前自动确认，让已掷出的面（例如币）仍能结算。
- 若整场从未达到 50 或玩家从未掷骰：本场无骰子加成，合法结束。

## 5. 战斗中的骰子规则（无锁骰、无重掷）

### 5.1 删除的内容

- 删除 **锁骰**。
- 删除 **重掷**（不要花能量全重掷，也不要「先重掷再叠加裂纹」的流程）。
- 删除战前掷骰、战前结算、出征时的骰子加成。
- 删除 `TacticalWindow`。状态机：`Setup` → `Countdown` → `AutoCombat` → `Resolve`。AutoCombat 不暂停。同调 **只保留数值 ×1.80**，不再解锁战术窗口，也不另做自动专属战术。

### 5.2 一轮怎么走

1. 能量 ≥ 50，玩家点掷骰：扣 50，立刻掷出 3 枚（六面等权，随机仍走本场种子）。
2. 玩家确认，或 6 秒超时 / 战斗结束自动确认。
3. 确认时按这 3 面结算双生 / 同调与骰面效果，**立即生效**，写 `dice_commit` 与 `combo_resolved`。本场结束，不能再掷。

万能符印、组合判定仍用主文档 §4.4（自动指定到最高档组合）。没有锁骰、没有重掷步骤。

### 5.3 确认时效果怎么落地（相对主文档的时机修正）

骰面数值与组合系数不变，只改 **生效时刻 = 确认当下**，并继续使用出征时的前中后排快照：

| 面 | 确认时 |
|---|---|
| 剑 / 锋刃 | 全队攻击 +12%（可被双生 / 同调放大），快照前排立即获得锐意层数 |
| 盾 / 壁垒 | 全队护甲 +8；快照前排立即获得 15% 最大生命护盾，从此时起算 8 秒 |
| 星 / 秘仪 | 快照后排 **立即** +20 技能能量（不再叫「初始能量」，数值不变）；之后技能伤害 +10% |
| 羽 / 疾行 | 全队攻速 +15%；每个单位当前技能冷却 −1 秒（最低 0），若首个技能尚未释放则其首个技能冷却仍按主文档 −1 秒 |
| 币 / 贪欲 | 本场胜利金币 +6（确认在失败结算前完成才算数；自动确认发生在 Resolve 之前） |
| 颅 / 献祭 | 全队立即损失 5% 当前生命（至少留 1 点）；获得本场临时万能符印，参与当次组合判定 |

### 5.4 裂纹与腐蚀（M0 暂不启用）

主文档里的裂纹（`status_crack`）与腐蚀（`mod_corrosion`）原先只靠「额外重掷」叠层。本补丁删除重掷后，M0 **没有** 获得裂纹的途径。

**M0 不启用裂纹和腐蚀**：不积层、不乘 1.15、不做替代获取手段，也不另发明大机制。规则与数值保留在主文档中，留给后续切片（若当时有非重掷的来源再启用）。
